====================================================
  GiWiFi 校园网自动登录助手 · 使用说明
  （v1.11.0）
====================================================


【这是什么】

连上宿舍 WiFi 后自动完成 GiWiFi 校园网认证的小工具。
掉线会自动重登，开机自动启动，不用再每次打开浏览器手动输账号密码。


【怎么用】—— 4 步

  1. 把整个文件夹解压到任意位置（例如 D://GiWiFi）
     * 不要只把 exe 拖出来单独用！config.json 必须和 exe 放在同一个文件夹里。

  2. 双击  GiwifiAutoLogin.exe

  3. 填你的校园网账号（手机号）和密码，点「保存并应用」
     （账号密码会加密存在本机，下次打开自动填好，不用重输）

  4. 宿舍 WiFi 那一栏从下拉框里选你宿舍的网络，
     勾上「记住并自动连接」，再点一次「保存并应用」

  完成。之后它会自己盯着网络，掉线自动重登。


【程序会自动做什么】

  * 启动后立刻打开 Wi-Fi 开关（如果你的无线网卡开关是关着的），
    并马上发起连接 —— 一般几秒钟就能上网。
  * 没连上你指定的那个 WiFi 时，自动帮你连过去。
  * 每隔 10 秒检测一次外网；一旦不通就自动重新认证。
  * 认证失败会**弹提示告诉你**，然后每 5 秒重试一次，直到成功。
  * 点右上角 × 只是把窗口收进托盘，程序继续在后台保持在线。
  * 开机后自动在后台启动（没有窗口，也不会有黑框一闪）。

  想关掉开机自启：打开界面，点一下「开机自启：已开启」按钮。


【开机后想看得见它？勾一个选项就行】

  默认开机自启是「完全静默」的 —— 后台在跑，但托盘区看不到任何图标。
  如果希望开机后能看见它、能随手点它，就在界面底部勾上：

      ☑ 开机自启后显示托盘图标（右键可打开窗口 / 立即登录 / 退出）

  勾上之后的区别：

  * 开机后托盘区会出现图标，鼠标悬停能看到当前状态
    （在线 / 正在登录 / 等待启动 / 登录失败…）
  * 右键图标：打开主窗口 / 立即登录 / 暂停·恢复监控 / 退出程序
  * 双击图标：打开主窗口

  几点说明：

  * 勾选后**立即保存**，不用再点「保存并应用」。
  * 这个选项是给**开机自启的后台**用的，所以要**下次开机**才看得出效果
    （当前打开的这个窗口本来就有托盘图标）。
  * 不勾 = 和以前完全一样，开机后托盘区干干净净。
  * 打开窗口时后台会把自己的图标收起来，**不会出现两个一样的图标**。


【连上 WiFi 老自动弹出浏览器登录页？可以关掉】

  每次连上宿舍 WiFi，Windows 都会自动弹一个浏览器窗口，把校园网认证页推到
  你面前 —— 这是 **Windows 自己**干的（它的"强制门户探测"一发现网络被劫持，
  就按设计主动打开浏览器），不是浏览器插件作乱，也不是本程序。

  既然本程序会自己在后台把认证做完，这个页面就是多余的。关掉的办法：

      界面底部 → 勾上
      ☑ 拦截连接 WiFi 时自动弹出的浏览器登录页（需管理员权限）

  勾上后会弹**一次** UAC 授权框（改系统设置需要管理员权限），点「是」即可。
  之后连 WiFi 就清清爽爽，不再跳网页了。

  注意事项：

  * 重连一次 WiFi 或重启电脑后**完全生效**。
  * 副作用：Windows 不再主动测网络，任务栏图标**可能不再显示"无 Internet"
    的感叹号**；个别应用（应用商店等）判断联网状态会慢一点。
    网络本身、浏览器、游戏都不受影响，**本程序也完全不受影响**。
  * 想恢复原样：把那个勾取消即可（Windows 又会自动弹登录页）。


【窗口关了，程序还在跑吗】

  还在。
  * 点右上角 × = 只是把窗口收进系统托盘，网络认证不会中断。
  * 双击托盘图标 → 重新打开窗口。
  * 右键托盘图标 → 「打开主窗口 / 立即登录 / 暂停·恢复监控 / 退出程序」。
  * 想**彻底退出**：点界面上的「退出程序」，或托盘菜单里的「退出程序」。
    （它会连同开机自启的后台实例一起退出，不会留残留进程）


【认证失败时会怎样】

  * 首次失败会弹一个提示框告诉你是怎么回事。
  * 然后每 5 秒自动重试一次，直到成功；成功后恢复正常节奏（10 秒一次）。
  * 每次开机第一次认证常常会被门户拒绝，紧接着第二次就成功 —— 属于正常现象。
  * 如果一直失败，多半是账号或密码不对，请打开界面重新填写。
  * 不想看到提示框：把 config.json 里 "alert_after_fails" 改成 0
    （只写日志不弹窗）；改成 2 或 3 则表示失败到第 2/3 次才弹。


【账号密码存在哪？安全吗】

  密码用 Windows 自带的 DPAPI 加密后存在 config.json 里，
  密钥绑定「这台电脑 + 当前 Windows 用户」。
  * config.json 里看不到明文密码
  * 把文件拷到别的电脑或别的 Windows 用户下，密文就解不开了（需要重新填）
  * 界面上密码默认是圆点掩码，想看明文可以勾右侧的「显示」
  * 保存后不会清空输入框，也不用担心「密码丢了」——它一直在配置文件里


【这个程序会访问我的位置信息吗】

  不会。Windows 把「读取 Wi-Fi 信息」也算作一次位置访问，所以有些
  连 WiFi 的工具会被系统记录成「频繁访问位置」。本程序只在**真正需要**
  的时候才去读当前 WiFi 名字：
  * 已经能上网时不读；
  * WiFi 设为「不限制」时不读；
  * 窗口收进托盘后不刷新显示。
  实测后台常驻运行期间，位置访问次数为 0。
  （可在「设置 → 隐私和安全性 → 位置信息 → 最近活动」里自行核对）


【注意事项】

  * 适用于 GiWiFi 校园网（网关地址可在 config.json 里改成你学校的）。
    如果换了学校 / 网关地址不同，用记事本打开 config.json，
    把 "portal" 改成你学校的认证地址即可。

  * 需要 Windows 10 / 11，不需要安装 Python。

  * 如果 Windows 弹出「已阻止此应用」「此应用存在风险」之类的提示，
    说明系统对未数字签名的程序比较严格（Smart App Control / SmartScreen）。
    可以：
      a) 在提示里选择「仍要运行」；
      b) 或改用「源码-备用」文件夹里的方式运行（那个需要装 Python）。

  * 「自动连接 WiFi」的前提是：这台电脑之前**手动连过一次**那个网络
    （Windows 需要先有该网络的无线配置文件）。没有的话程序会提示你先手动连一次。


【出问题了看哪里】

  * 打开界面，底部「运行日志」会实时显示每一步在做什么。
  * 同目录下的 giwifi.log 也会记录（超过 512KB 自动滚动）。
  * 想在命令行里排查，可以用源码目录里的：
        python GiwifiAutoLogin.pyw --diag      环境诊断
        python GiwifiAutoLogin.pyw --once      只跑一次，看结果


【文件夹里都有什么】

  GiwifiAutoLogin.exe   ← 主程序，双击运行
  config.json           ← 你的配置（账号、密码密文、WiFi 设置）
  giwifi.ico            ← 图标
  使用说明.txt          ← 本文件
  README.md             ← 完整技术文档（含协议逆向过程）
  源码-备用\            ← 源代码。没装 Python 可以忽略；
                          如果 exe 被系统拦住，可以在这里找替代启动方式
