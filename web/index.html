一键认证脚本生成器

粘贴你学校认证页面的网址（自动识别门户地址），填入校园网账号密码，生成一段认证脚本；在校园网内打开门户登录页，把它粘到浏览器控制台（按 F12 → Console）回车，即可完成认证。整个过程在你的浏览器本地完成，本页面不收集、不上传任何信息。

使用步骤

  1. 确认你的设备已连接校园网 Wi-Fi（还没认证也能连上，只是上不了外网）。
  2. 浏览器打开门户地址：—（应能看到登录页）。
  3. 按 F12 打开开发者工具，切到 Console（控制台）标签。
  4. 把下面整段脚本粘贴进去，按 回车 —— 弹窗显示认证结果。

      
⚠ 脚本里已包含你的账号密码，请像保管密码一样保管它，用完即删、不要发给他人。

协议流程（与客户端实现一致）

    

      
步骤请求说明

      
1GET /gportal/web/login拉取登录页，解析 #frmLogin 表单隐藏字段（sign / iv / nasName / userIp…）

      
2本地加密按 DOM 顺序序列化表单（替换账号密码字段），AES-128-CBC + ZeroPadding 加密 → Base64

      
3POST /gportal/web/authLogin?round=N提交 data=<密文>&iv=<iv>，响应 JSON 的 status/success 表示结果
